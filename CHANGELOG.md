# What's new?

## 2026
We changed from (ir-)regular releases to continuous releases.
Every change that is merged into main will trigger a new release to get changes out there as quickly as possible. 
That's also why the version number changed.
It now contains the year, the month, the day, and the build on that particular day.  

## 2025.1
We added a lot of new terms and fixed some explanations with this release.
We decided to use a new major version since two years passed since the last release. 

## 2023.1
This is the very first GitHub release of the iSAQB® Glossary for Software Architecture Terminology.
