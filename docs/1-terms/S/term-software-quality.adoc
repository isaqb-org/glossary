[#term-software-quality]

// tag::EN[]
==== Software Quality

Quality is a measure (in the sense of measurement) that describes the fulfillment of stated or implied requirements.

A quality comprises:

- the <<term-software-property,properties>> to which it refers,
- how it is measured or compared, and
- what the criterion on the measurement is that specifies fulfillment of the requirement.

// end::EN[]

// tag::DE[]
==== Softwarequalität

Qualität ist ein Maß, das die Erfüllung von ausgewiesenen oder impliziten Anforderungen beschreibt.

Zu einer Qualität gehört:

- die <<term-software-property,Eigenschaft>>, auf die sie sich bezieht,
- wie sie gemessen oder verglichen wird und
- was das Kriterium auf die Messung ist, das Erfüllung der Anforderung spezifiziert.

// end::DE[]
