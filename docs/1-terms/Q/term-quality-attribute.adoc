==== Quality Attribute

Ill-defined term that may refer to:

- a <<term-quality-characteristic,quality characteristic>>, or
- the result of measuring a particular quality of a software system.

Don't use.

// end::EN[]

// tag::DE[]

==== Qualitätseigenschaft

Unklarer Begriff, der sich beziehen kann auf:

- ein <<term-quality-characteristic,Qualitätsmerkmal>> oder
- das Ergebnis der Messung einer bestimmten Qualität eines Softwaresystems.

Nicht verwenden.

// end::DE[]
