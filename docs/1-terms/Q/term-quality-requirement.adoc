[#term-quality-requirement]

// tag::EN[]
==== Quality Requirement

Ill-defined term that may refer either to:

- a requirement on a specified <<term-software-property,property>>, or to
- a requirement on a specified non-functional <<term-software-property,property>>.

Don't use.

// end::EN[]

// tag::DE[]
==== Qualitätsanforderung

Unklarer Begriff, der sich beziehen kann auf:

- eine Anforderung auf eine spezifizierte  <<term-software-property,Eigenschaft>>, oder
- eine Anforderung auf eine spezifizierte nicht-funktionale <<term-software-property,Eigenschaft>>.

Nicht verwenden.

// end::DE[]
